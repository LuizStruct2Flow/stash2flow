# `doing/` — work in progress

Active work being implemented. `BUGS.md` and `HANDOVER.md` are always here.
Everything else appears WHEN IT IS FIRST NEEDED and not before:
`BACKLOG.md` when a parked row is promoted, `PLAN-*.md` for a major bug or
feature, and multi-file epics in their own folders (`BUG-XXX-<slug>/`,
`SPIKE-XX-<NAME>/`, `SLICE-XX-<NAME>/`).

That distinction is deliberate. An absent `BACKLOG.md` means nothing has been
promoted — not that a file is missing.

Lifecycle (DoD §lifecycle):
`doing/` → `waiting-acceptance/` on push → `done/` on founder acceptance → back to `doing/` on rejection.

The `HANDOVER.md` in this folder is the canonical "where are we right now"
resume doc — keep it current at sleep/wake transitions.
